# E-Commerce with Testing

This project was developed for the SE5102: Software Testing course module at Sabaragamuwa University of Sri Lanka. It highlights the integration of software development and testing practices to ensure the quality and functionality of a full-stack eCommerce platform.

<h3><u>Technologies </u></h3>

🔹 Frontend: React, Tailwind CSS<br>
🔹 Backend: Node.js, Express<br>
🔹 Database: MongoDB<br>
🔹 Authentication: JSON Web Tokens (JWT)<br>

<h3><u>Features</u></h3>

<h4>User Features</h4>
✅ Secure Authentication (Register/Login).<br>
✅ Browse products by categories.<br>
✅ Advanced Search, Sorting, and Filtering capabilities.<br>
✅ View detailed product information.<br>
✅ Manage shopping cart items.<br>
✅ Smooth checkout process.<br>

<h4>Admin Features</h4>
✅ Product Management: Create, Read, Update, and Delete (CRUD) operations for products.<br>
✅ User Management: Admin panel for managing user accounts.<br>


<h3><u>Testing Practices Implemented</u></h3>

✅ Created Test Cases: Comprehensive test scenarios to validate functionalities.<br>
✅ Test Plan Document: Detailed plan covering testing objectives, scope, and strategies.<br>
✅ Executed Tests: Using Jest for unit testing and Mockito for mocking.<br>
✅ UI Automation: Performed Selenium testing to automate UI workflows.<br>
✅ Code Coverage Reports: Generated reports to ensure robust and maintainable code.<br>
